# ChatBot con LLaMA 3.1

Este proyecto implementa un chatbot interactivo utilizando el modelo LLaMA 3.1 y Streamlit para la interfaz de usuario. El chatbot puede responder a preguntas de los usuarios y mantener el contexto de la conversación.

## Características

- **Interfaz de Usuario con Streamlit**: Proporciona una interfaz web sencilla para interactuar con el chatbot.
- **Personalización del Asistente**: Permite definir el nombre y la descripción del asistente virtual para adaptar su comportamiento.
- **Manejo de Historial de Conversación**: Mantiene el contexto de la conversación para proporcionar respuestas coherentes.

## Requisitos

- Python 3.8 o superior.
- Bibliotecas especificadas en `requirements.txt`.
